# Cardputer-Base-Converter
Carputer compatible Base Converter 
## warning, not tested yet, may not work perfectly on cardputer
<br>
<br>
<h2>What It Does</h2>
<h4>this tool is intended to be a base converter for bases that only use 0-9(plus Hex). You can convert freely between bases, excluding Hex.</h4>
It supports: 
<br>
- Binary
<br>
- Octal
<br>
- Decimal
<br>
- Hex*
<br>
<br>
*the Hex line actively shows the hex value of your current value, but you cannot input your own hex value.

<h2>How To Use<h2>
<h4>Step 1: collect the components and wire them, or test it in Wokwi: https://wokwi.com/projects/469655274763918337</h4> 
<h4>Step 2: move between the bases using up and down arrow key, and hit enter once the ">" is on the correct base</h4>
<h4>Step 3: input the numbers you want converted in that base, and once completed you can select a different base and it will automatically convert that value</h4>
